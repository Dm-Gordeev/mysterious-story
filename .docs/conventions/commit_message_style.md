# Стиль коммит-мессаджей

Источник истины — этот файл. Стиль НЕ выводить из `git log --oneline`: он показывает только заголовки и скрывает тела, поэтому по нему репа выглядит «однострочной», чем не является.

## Заголовок

- Английский, lowercase, без точки в конце, до ~120 символов.
- Про наблюдаемое поведение/результат, а не механику: «fix far cats grabbing haul tasks», не «add distance check to assignment».
- Баги — «fix» + что сломано: «fix cats freezing at destination cell».
- Изменения поведения — допустим оборот «don't X when Y»: «don't walk to the tile center when already inside the target tile».
- Опциональный префикс области, если правка вся внутри одной подсистемы/UI-окна: «storage window: ...».
- Conventional-префиксы (feat:/fix:/refactor:) допустимы, но не обязательны — стилю не мешают.

## Тело (опционально)

- Отделяется от заголовка пустой строкой; строки тела переносятся ~72 символа.
- Английский; сплошной текст — предложения с заглавной, буллеты можно со строчной.
- Содержимое: почему так сделано, первопричина бага, детали реализации, которым тесно в заголовке.
- Буллеты «- », продолжение пункта — с отступом 2 пробела.

## Патчноуты

Специальных тегов (internal:/docs:) для фильтрации не заводим — при сборке патчноутов Claude сам отсеивает технические коммиты по содержанию. Чтобы это работало: заголовок держим про поведение, а внутреннюю механику уносим в тело.
